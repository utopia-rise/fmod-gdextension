# E.2: Inspector

The Inspector edits FMOD nodes with FMOD-aware controls: event and bank pickers, and event parameters.

Typing event paths and GUIDs by hand is error-prone. The addon's Inspector editors let game developers pick events and banks from the project's banks, and show an emitter's parameters with their ranges.

## Capabilities
- **E.2.1**: Game developers pick an emitter's event from the project's banks in the Inspector, which fills both its path and its GUID.
- **E.2.2**: Game developers add, remove and reorder a bank loader's banks in the Inspector, picking them from the banks folder or typing a path.
- **E.2.3**: The Inspector shows an emitter's event parameters within the range defined in FMOD Studio, and resets them to their default value.
