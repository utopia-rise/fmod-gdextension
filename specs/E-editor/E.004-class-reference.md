# E.4: Class reference

The extension's classes are documented in Godot's built-in help, like engine classes.

Godot users look up an API with the editor's help and its tooltips (§2). Every class, method, property and signal the extension registers has its description there.

## Capabilities
- **E.4.1**: Game developers read the description of every FMOD class, method, property, signal and constant in the editor's help and Inspector tooltips.
